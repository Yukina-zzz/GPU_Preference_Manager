## 项目初衷

面向显示器分别连接核显和独显等混合输出场景，集中查看每个程序实际使用的 GPU，并直接调整应用偏好，避免反复进入 Windows 设置手动寻找 EXE、逐个添加和修改。

## 0.9.0 主要内容

- 可在本软件中手动修正唯一的高性能 GPU 与节能 GPU，不改写 Windows 全局 `HighPerfAdapter`；
- 增加适配器排除列表、手动排除、恢复及自动排除项强制恢复；
- 强制恢复不会绕过无效或重复 SpecificAdapter 设备键保护；
- 程序行增加右键快捷偏好和忽略操作，多 EXE 应用会先明确选择实际可执行文件；
- 右键菜单打开期间继续后台采样但冻结表格，避免实时排序移动行或关闭菜单；
- 右侧应用详情改为分区卡片布局，GPU 占用、路径、偏好、进程与采样信息更紧凑；
- 设置升级到 Schema v3，适配器自定义按稳定设备实例路径持久化；
- 保持运行期间不重新枚举显卡，拓扑变化后仍需重启本程序。

- 当前 EXE 未进行代码签名，可能触发 SmartScreen 提示；
