## 项目初衷

面向显示器分别连接核显和独显等混合输出场景，集中查看每个程序实际使用的 GPU，并直接调整应用偏好，避免反复进入 Windows 设置手动寻找 EXE、逐个添加和修改。

## 0.8.0 主要内容

- 使用 DXGI、DisplayConfig 和设备实例信息识别物理、虚拟及软件适配器；
- 通过 PDH 显示应用与子进程的实时 GPU、专用显存和共享显存占用；
- 支持前台应用/后台进程、搜索、自定义筛选、排序及多进程展开；
- 多 EXE 应用可以明确选择实际写入目标，并提示同组规则不一致；
- 支持通用节能、通用高性能、特定适配器和清除偏好；
- 提供注册表备份、SQLite 历史、写后校验、失败补偿、撤销与回滚；
- 非 `REG_SZ` 值拒绝写入和类型降级回滚；
- SQLite 原生依赖已升级到 2.1.12，NuGet 漏洞扫描未发现已知易受攻击包；
- 清理已失效的开发主规格、旧手工报告和版本流水账。

## 下载

- Portable ZIP：解压后运行 `GpuPreferenceManager.exe`；
- Single EXE：启用内置压缩的单文件自包含版本；
- `SHA256SUMS.txt`：两项发布文件的 SHA-256 校验值。

## 使用前须知

- 仅支持 Windows 11 x64；
- 当前 EXE 未进行代码签名，可能触发 SmartScreen 提示；
- 本工具设置的是 Windows GPU 偏好，不是驱动级强制规则；修改后需重启目标程序并核对实际 GPU 活动；
- 运行期间不会重新枚举显卡；显卡热插拔、驱动重启或拓扑变化后需重启本程序；
- 本项目尚未经过独立的专业安全审计。
